# Furnitur Production

Портфолио-сайт мастерской корпусной мебели на заказ (Батуми, Махинджаури).

Статичная одностраничная HTML-версия — без сборки и зависимостей:

- `index.html` — вся разметка, стили и скрипты (включая WebGL-шейдер фона в hero)
- `img/` — фотографии портфолио

## Просмотр

Открыть `index.html` в браузере, либо включить GitHub Pages для этого репозитория
(Settings → Pages → Source: `main` / root).

## Технологии

Чистые HTML/CSS/JS. Двуязычный контент (русский/грузинский). Тема адаптируется
под системные light/dark настройки.
