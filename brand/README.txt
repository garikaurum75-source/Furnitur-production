FURNITUR PRODUCTION - логотип / ლოგოტიპი

Идея: болнисский крест (грузинский символ) с расширяющимися лучами похож на
столярное соединение "ласточкин хвост". Крест собран из четырёх вставок
из ореха и латуни, центр красный - отсылка к флагу Грузии.

svg/  - векторные файлы (печать, вывеска, наклейки, любой размер без потери качества)
  logo.svg           - основной логотип для светлого фона
  logo-on-dark.svg   - для тёмного фона
  emblem.svg         - только эмблема (значок, штамп, гравировка)

png/  - готовые картинки
  logo-transparent.png / logo-on-dark-transparent.png - на прозрачном фоне
  logo-white-background.png / logo-dark-background.png - на сплошном фоне (для мессенджеров, документов)
  emblem-transparent.png - эмблема без фона
  avatar-dark.png / avatar-white.png - квадратный аватар 1024x1024 (WhatsApp, Instagram, Facebook)

Цвета:  орех #7A4B2A   латунь #D2A857   красный #E4141B
        текст (светлый фон) #2A1A0F   текст (тёмный фон) #F3ECDF
Шрифты (переведены в кривые, устанавливать не нужно): Piazzolla Bold, Manrope Bold
